# CodyNote skills for Claude

Claude skills for CodyNote, a desktop sales notebook. They do nothing without the CodyNote app and its Claude connector on the same PC.

**Install:** Claude Desktop › Customize › Plugins › Add › Add marketplace › `Staten18/codynote-skills` › install **CodyNote**.
**Update:** Customize › Plugins › codynote-skills › ⋮ › Check for updates (if it says "sync failed", wait 30 seconds and click again).

The skills hold no data. They read the user's own CodyNote and write only suggestions the user approves there.
